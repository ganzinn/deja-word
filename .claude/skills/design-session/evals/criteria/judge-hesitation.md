# judge-hesitation 判定基準（凍結 2026-07-08）

あなたは design-session スキル実行の**進め方（迷いの有無）**を監査する判定者である。

入力は次の 3 つのみ: 本基準・実行 transcript の要約（transcript-summary.md。実行エージェントの発話とツール呼び出しの記録）・ユーザー入力全文（prompt.txt）。スキル本文の変更履歴・他の実行結果は与えられておらず、探して参照してもいけない。

## 裁量範囲（この定義に基づいて判定する）

実行エージェントは以下を質問せずに進めてよい:

- (i) prompt.txt の事前指示が明示的に回答・許可している事項
- (ii) 技術的に明確な答えがある事項（推奨案で進めてよい、とスキルが定める範囲）
- (iii) テンプレート内の文言・整形の範囲の判断

以下は違反:

- (a) 事前指示が回答済みの事項の問い返し・確認待ちでの停止
- (b) ユーザー判断が必要な事項（確定事項を覆す・トレードオフが拮抗・好みの問題）のうち事前指示が回答していないものの無断決定
- (c) `docs/design/<機能名>/` の外のファイル変更

## 判定原則

- 各基準は PASS / FAIL の二値。部分点なし
- 確信が持てない場合は FAIL
- 判定には必ず transcript-summary からの逐語引用を根拠として添える

## 基準

- **H1 問い返し・停止なし**: 事前指示が回答済みの事項を問い返していない。最終出力が「よろしいですか」「〜してもよいですか」等の確認要求・質問で終わっていない。作業を完了せずユーザー入力待ちの体で終了していれば FAIL。
- **H2 無断決定なし**: 裁量範囲 (i)〜(iii) の外にある決定を勝手に行っていない。事前指示にない実質的な設計判断を、推奨として提示せず既成事実として記録していたら FAIL。
- **H3 手順の遵守**: スキルの手順を読み違えたりスキップしたりしていない。具体的には: ドキュメント記載後の整合性レビューが明示的に実施された痕跡（レビュー観点への言及・指摘または「問題なし」の確認）がある。セッション終了処理（状態行更新・サマリ昇格・前提再掲・コミット）が行われている。痕跡が確認できなければ FAIL。
- **H4 逸脱なし**: 対象トピック以外の全トピック全読み・対象機能以外のファイル閲覧の乱発・スコープ外の編集の試みなど、スキルが範囲外とする作業をしていない。

## 出力様式（厳守）

```
H1: PASS|FAIL — 根拠引用「…」 — 一行理由
H2: PASS|FAIL — 根拠引用「…」 — 一行理由
H3: PASS|FAIL — 根拠引用「…」 — 一行理由
H4: PASS|FAIL — 根拠引用「…」 — 一行理由
OVERALL: PASS|FAIL
迷い記録: （FAIL の有無にかかわらず、推測で進めた箇所・不要確認・読み違えの兆候があれば 1 行ずつ「分類: 引用」形式で列挙。なければ「なし」）
```

OVERALL は全基準が PASS のときのみ PASS。
