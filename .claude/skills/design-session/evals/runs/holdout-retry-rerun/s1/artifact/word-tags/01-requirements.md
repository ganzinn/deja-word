## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- アプリのコンセプトは「一度忘れた単語との再会」による定着支援。word-tags はその再会を助ける学習整理の補助機能。
- MVP はタグの作成・単語への付け外し・一覧のタグ絞り込みまで。タグの共有・色分け・並び替えはスコープ外（本トピックで明文化する）。

## 検討事項リスト

- [ ] タグで解決したいユーザーの課題は何か（「覚えにくい単語のグルーピング」の具体像・コンセプト「再会」との関係）
- [ ] タグの粒度・自由度（自由記述の単一次元タグのみか、命名の制約・最大数などの方針）
- [ ] タグ付けの対象単位（単語エンティティ単位か、掲載箇所単位か。既存一覧の 2 表示モードとの関係）
- [ ] 共有単語（system user 由来）にもタグを付けられるか、付けられる場合そのタグは誰のものか（私的か）
- [ ] 絞り込みの体験（単一タグか複数タグか、複数指定時の意味＝AND/OR、既存の検索・掲載箇所絞り込みとの併用）
- [ ] タグの管理操作（作成・改名・削除）をどこまで MVP に含めるか、削除時の付与済み単語の扱い
- [ ] スコープ外とするもの（共有・色分け・並び替え、その他）
