+### 決定 1: 付け外しは星アイコンのトグルで行い、単語一覧の各行と単語詳細画面に置く
+
+ブックマークの付け外しは星アイコン（lucide `StarIcon`）のトグルボタンで行う。設置箇所は 2 か所:
+
+- 単語一覧の各行の右クラスタ（既存の `MY` バッジ・発音ボタン `RowAudioButton` が並ぶ `ml-auto` の並び）。
+- 単語詳細画面のヘッダ操作エリア（`ScreenHeader` の `actions` スロット。既存の編集・削除アイコンが並ぶ場所）。
+
+いずれもクリックで即時にオン/オフを切り替える。星の塗り/枠でオン/オフ状態を示す。
+
+採用理由: 一覧・詳細のどちらの文脈でも「いま見ている単語」にその場で印を付けられ、反復学習の手数が最小になる。既存の行アクション（`RowAudioButton`）・ヘッダアクション（編集・削除アイコン）の設置パターンを踏襲でき、見た目と実装の一貫性が保てる。
+
+却下した代替案:
+- 単語詳細画面のみに置く。一覧から素早く付け外しできず、複数語をまとめて印付けする用途で手数が増えるため却下。
+- 専用のブックマーク管理 UI（一括編集画面など）。決定 1（オン/オフの二値・階層なし）に対して過剰で、最小操作の方針に反するため却下。
+
+### 決定 2: 「ブックマーク済みのみ表示」は既存の単語一覧ツールバーの絞り込みとして統合する
+
+見返す動線は、既存の単語一覧ページのツールバー（検索・並び替えと同じ URL パラメータ方式の絞り込み群）に「ブックマーク済みのみ表示」のトグルを 1 つ追加して提供する。専用ページは設けない（01 決定 2 の改訂を受けた UI 側の帰結）。
+
+採用理由: ページを増やさず、既存の絞り込み基盤（URL パラメータ → サーバ再取得）にそのまま乗せられる。ユーザーは慣れた一覧の操作系の延長で見返せる。絞り込みの内部構成（パラメータ名・データ取得）は 04 で扱う。
+
+却下した代替案: 専用ページ `/bookmarks`。ページを増やすコストに見合わず、一覧の絞り込みで用途を満たせるため却下（経緯は [01](01-requirements.md) 決定 2 の改訂履歴）。
+
+### 決定 3: 絞り込み適用時も通常の単語一覧と同じ表示項目にする
+
+「ブックマーク済みのみ表示」を適用した状態でも、各行の表示項目は通常の単語一覧と同一とする。ブックマーク専用の追加表示（登録日時・専用の並びなど）は設けない。
+
+採用理由: 同じ一覧の絞り込み結果である以上、表示を変える理由がなく、実装・認知コストを最小にできる。追加表示の需要が出たら別途トピック化する。
+
+却下した代替案: 絞り込み時に専用の表示項目（ブックマーク登録日時など）を出す。MVP には不要で列・情報量が増えるだけのため却下。
