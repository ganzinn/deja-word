# 02. エクスポート形式

状態: **確定**（2026-07-05）

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- エクスポート対象は本人の登録単語のみ・形式は CSV（01 確定）。

## 検討事項リスト

- [x] 列の構成
- [x] 文字コード

## 議論・決定

### 決定 1: 列は 単語・意味・登録日 の 3 列とする

採用理由: 復習・保管に必要な最小構成に絞る。列が必要になったら追加は後方互換で行える。

却下した代替案: 学習履歴（正答率等）を含める。集計定義が未確定で、含めると形式が不安定になるため却下。

### 決定 2: 文字コードは UTF-8（BOM 付き）とする

採用理由: Excel でそのまま開いたときの文字化けを避けるため。

却下した代替案: BOM なし UTF-8。Excel の既定挙動で文字化けするため却下。
