## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 目標はユーザーごとに 1 つ・種類は週あたりの復習単語数のみ（01 確定）。
- 目標値は正の整数 1〜999、デフォルトなし（未設定＝オプトイン）、設定画面で変更・解除できる（01 確定）。
- 「復習した」= 週内に解答した単語のユニーク数。全 mode（TEST / DRILL / DRILL_RETRY）・正誤問わず `QuizAnswer` の週内 distinct `wordId`（01 確定）。
- 進捗は永続化せず `QuizAnswer.createdAt` から都度算出する。達成カウンタ・達成履歴テーブルは持たない（01 確定）。
- 目標設定は本人行のみ upsert（ユーザー単位設定。ownerId を持たず userId 主キー）。進捗集計は本人の解答のみ（01 確定）。
- 既存の per-user 設定テーブルとして `UserPreference`（PK=userId・全項目任意・横断設定の集約）と `QuizDefaultSetting` がある。→ word-quiz / user-preferences 実装。
