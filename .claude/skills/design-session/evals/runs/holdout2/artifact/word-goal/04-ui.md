## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 進捗表示はログイン後トップ `/menu`。未設定時は「学習目標を設定する」導線、設定済み時は「今週 X / Y 語」＋達成率の視覚表示（バー等）（01 確定）。
- 達成時（X ≥ Y）は進捗表示が満了になるだけ。通知・お祝い演出・バッジはしない（01 確定）。
- 目標のユースケースは 設定 / 変更（上書き）/ 解除 / 今週の進捗確認（01 確定）。
- 目標値は正の整数 1〜999。デフォルトなし・未設定はオプトイン（01 確定）。
- 目標は今週のみ表示（過去週の表示なし）（01 確定）。
- 既存の設定画面は `/settings/*`（general / occurrences / quiz-defaults）で、`/settings/page.tsx` のハードコード `<Link>` リストに 1 項目追加が定石。フォームは `"use client"` + `useForm` + `zodResolver` + Server Action + `sonner` toast。→ 既存実装。
