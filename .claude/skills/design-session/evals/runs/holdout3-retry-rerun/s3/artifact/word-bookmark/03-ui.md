# 03. UI

状態: **確定**（2026-07-08）

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- ブックマークは単語単位のオン/オフ（01 確定）。
- 見返す動線は単語一覧ページの「ブックマーク済みのみ表示」フィルタで提供する（01 確定）。
- 保存は中間テーブル UserWordBookmark（02 確定）。

## 議論・決定

### 決定 1: 付け外しは一覧の各行と単語詳細画面の星アイコンで行う

単語一覧（`/words` の単語ビュー）の各行と、単語詳細画面（`/words/[id]`）の双方に星アイコンを置き、クリックでブックマークの付け外しをする。星は付与済み/未付与を塗り分けで示す。アイコンは既存踏襲で `lucide-react` の `StarIcon` を使う。

一覧の各行はもともと詳細への遷移リンクになっているため、星アイコンは行リンクとは独立した操作要素として扱う（行本体クリック＝詳細へ遷移、星クリック＝ブックマーク切替）。

採用理由: 一覧を眺めながらでも、詳細を開いた状態でも、その場で付け外しできるようにするため。見つけた瞬間に印を付けられる動線を最優先する。

却下した代替案:
- 詳細画面のみに置く。一覧を眺めている最中に付けられず、都度詳細を開く手間が増えるため却下。
- 一覧の行全体クリックで付け外し。行は詳細への遷移に割り当て済みで、遷移と切替が衝突するため却下。

### 決定 2: 見返すフィルタは単語ビューのツールバーに「ブックマーク済みのみ」トグルとして置く

見返す動線は単語一覧ページの絞り込みで提供する（01 決定 2）。その入口を、単語ビューの一覧ツールバー上の「ブックマーク済みのみ表示」トグルとする。オンにすると一覧がブックマーク済みの単語だけに絞られる。

採用理由: 既存の一覧絞り込み（検索・並び順）と同じ場所に置くことで、絞り込み操作の一貫性を保てるため。フィルタ状態は既存の絞り込みと同じくクエリパラメータで表現する（URL 共有・戻る動線を既存挙動に合わせる）。実効するパラメータ名・データ取得の構成は 04 で扱う。

却下した代替案:
- ナビゲーション等からの独立した入口（実質的な専用ページ相当）。01 決定 2 で専用動線は設けないと確定済みのため却下。

### 決定 3: フィルタ適用時の一覧表示は通常の単語一覧と同じ項目にする

「ブックマーク済みのみ」で絞り込んだときも、行の表示項目は通常の単語一覧（見出し語・バッジ・意味・発音ボタン等）と同一にする。ブックマーク一覧専用の表示は作らない。

採用理由: 見返す用途では通常一覧と同じ情報で足り、専用表示を持つと実装・保守が二重になるため。既存の行コンポーネントをそのまま再利用できる。

却下した代替案: ブックマーク専用の表示項目・レイアウト。通常一覧と差を付ける必然性がなく、二重管理になるため却下。
