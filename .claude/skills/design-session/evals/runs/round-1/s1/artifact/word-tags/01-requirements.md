## 検討事項リスト

- [ ] コアユースケースの確定: タグの作成 / 単語へのタグ付け・外し / 一覧のタグ絞り込み。それぞれのアクター（本人のみ）とトリガ
- [ ] タグの所有単位: タグはユーザーごとに独立か（system 共有マスタは持たないか）。同名タグの他ユーザーとの独立性
- [ ] タグ付けの対象: `ownerId` が本人の単語のみか、system 共有単語（pass-through で本人が編集する語）にも付けられるか。付けられる場合の所有関係の扱い
- [ ] 絞り込みの UX 要求: 単一タグか複数タグ選択か。複数選択時の意味（AND / OR）（詳細セマンティクスは 03 へ渡す）
- [ ] 既存の一覧絞り込み（検索語 `q` / 掲載箇所 `occ` / 並び順 `sort`）との併用可否
- [ ] タグの改名・削除の要求有無（MVP に含めるか。削除時に付与済みの関連をどうするかは 02 へ渡す）
- [ ] 付与単語ゼロの「空タグ」を許容するか（作成のみで未使用のタグ）
- [ ] タグ名の制約（最大長・使用可能文字・空白のみ禁止など）の要求レベル（詳細ルールは 03 へ渡す）
- [ ] 1 単語あたり / 1 ユーザーあたりのタグ数上限を設けるか
- [ ] スコープ外の明示: タグの共有・タグの色分け・タグの並び替え（将来拡張として記録）
