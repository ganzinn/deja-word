+### 決定 1: トグル操作は各行と単語詳細の星アイコンで行う
+
+単語ビューの一覧各行と、単語詳細画面に星アイコン（lucide `StarIcon`）を置き、クリックで付け外しする。付いている状態は塗り、外れている状態は枠で表現する。
+
+- 実装参照: 発音トグル（`src/components/audio-play-button.tsx`）の `aria-pressed` + アイコン差し替えパターンを踏襲する。
+- 一覧の各行は全体が `<Link href={/words/:id}>` になっているため、行内の星アイコンは発音ボタン（`src/components/row-audio-button.tsx`）と同じく `onClick` の `preventDefault`/`stopPropagation`・`onKeyDown` の `stopPropagation` で行遷移を抑止する。
+- 掲載箇所ビュー（`?view=occurrence`）は今回対象外とする。ブックマークは単語単位であり、単語ビューの行と単語詳細で付け外しが完結するため。
+
+採用理由: 見ているその場で付け外しでき、専用の操作画面を要しない。既存の発音トグルと同じ流儀に揃えられる。
+
+却下した代替案: 一覧での複数選択＋一括操作。MVP には過剰で、1 件ずつのトグルで足りるため却下。
+
+### 決定 2: 見返しは単語一覧の「ブックマーク済みのみ」絞り込みで行い、表示項目は通常の一覧と同じ
+
+単語一覧ページ（単語ビュー）に「ブックマーク済みのみ表示」のトグルを 1 つ追加する。適用時も表示列は通常の単語一覧と同じで、専用の表示は作らない。
+
+- フィルタの状態は、既存の検索/一致方法/並び順フィルタと同じ **URL query param 方式**（例 `?bookmarked=1`）に揃える。param 名・デフォルト値の URL 省略・ビュー切替時の param 継承といった配線の詳細は 04（データ取得）で扱う。
+
+採用理由: ページを増やさず、一覧の絞り込みで見返す用途を満たせる。既存フィルタ（`word-list-toolbar.tsx` 等）と UI・状態管理を一貫させられる。
+
+却下した代替案: 専用ページ `/bookmarks`（01 決定 2 で覆した）。またフィルタ適用時に専用の表示項目を作る案も、通常の一覧と同じ情報でよく二重管理になるため却下。
+
+### 決定 3: 単語詳細の星アイコンは見出し語の行に置く
+
+単語詳細画面では、見出し語（`WordDetailView` の `<h2>`）の行、`MY` バッジと並ぶ位置に星トグルを置く。編集・削除（`ScreenHeader` の `actions`）とは分ける。
+
+採用理由: ブックマークは単語そのものの状態であり、編集・削除のような操作アクションより見出しの近くに置くほうが自然。既存の `MY` バッジと同じ「単語の属性表示」の並びに収まる。
+
+却下した代替案: `ScreenHeader` の `actions` に編集・削除と並べる。操作アクションと状態トグルが混在して意味が読みづらいため却下（レイアウト都合で actions 側に寄せる余地は実装時に残す）。
+
+## 補足（04 への申し送り）
