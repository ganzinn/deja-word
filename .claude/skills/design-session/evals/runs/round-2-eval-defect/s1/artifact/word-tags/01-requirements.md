# 01. 要求・ユースケース

状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 機能名は word-tags（タグ = ユーザー定義の自由な分類ラベル。既存の note / Memo とは別概念）。
- アプリのコンセプトは「一度忘れた単語との再会」による定着支援。タグはその整理を助ける補助機能。
- MVP はタグの作成・単語への付け外し・一覧のタグ絞り込みまで。共有・色分け・並び替えはスコープ外（ユーザー事前指示）。

## 検討事項リスト

- [ ] タグで解決したいユーザーの課題は何か（覚えにくい単語のグルーピング等、コンセプト「再会」との関係）
- [ ] タグを付けられる対象: 本人所有単語のみか、system 共有マスタ単語にも付けられるか（pass-through と同型の論点。02・05 に波及）
- [ ] タグ作成の導線: 専用の管理画面で作るか、単語への付与時にインラインで新規作成するか
- [ ] 単語への付け外しのユースケース（1 単語に複数タグ、1 タグに複数単語の前提でよいか）
- [ ] 一覧のタグ絞り込みの要求（単一タグか複数タグ選択か、既存の検索・並び順との併用可否）
- [ ] タグ自体のリネーム・削除を MVP に含めるか（作成・付け外しに閉じるか、ライフサイクル管理まで見るか）
- [ ] スコープ外として明示するもの（共有・色分け・並び替え、および上記で MVP 外にした項目）
