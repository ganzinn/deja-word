## 検討事項リスト

- [ ] タグの所有単位（ユーザーごとにタグ名前空間を持つ／単語の所有モデルに従う）
- [ ] タグの CRUD 範囲（作成は必須。改名・削除の要否と、削除時に既存の付与関係をどうするか）
- [ ] タグの新規作成の入口（専用の管理画面か、単語へのタグ付け時にその場で新規作成できるか）
- [ ] 単語へのタグ付け／外しのユースケース（どの画面から行うか、1 単語に複数タグ、1 操作で複数タグ）
- [ ] 一覧のタグ絞り込みの挙動（単一タグのみ／複数タグ選択時の合成規則＝AND・OR。詳細な合成ロジックは 03）
- [ ] 絞り込みと既存の単語一覧（並び順・ページング・検索）の関係
- [ ] 付与単語が 0 件になったタグ（空タグ）の表示・存続可否
- [ ] スコープ外の明示（共有・色分け・並び替え、および将来拡張として切り出す候補）
