## 議論・決定

### 決定 1: ブックマークは単語単位のオン/オフとする

単語 1 件に対して付ける・外すの二値のみ。フォルダ分けやラベルなどの階層構造は持たない。

採用理由: 最小の操作で使えることを優先する。整理の需要が出たらタグ等の別機能で扱う。

却下した代替案: フォルダ分け。MVP には過剰で、タグ機能と役割が重複するため却下。

### 決定 2: 見返す動線は単語一覧ページ `/words` の絞り込みで提供する（専用ページは設けない）

ブックマーク済みの単語だけを表示する絞り込みを既存の単語一覧ページ `/words` に追加する。専用ページ `/bookmarks` は設けない。

採用理由: ページを増やさずに済み、一覧の既存の絞り込み機構で「見返す」用途を満たせるため。

却下した代替案: 専用ページ `/bookmarks`。当初はこちらを採用していた（見返す動線を独立させ迷わずたどり着けるようにする狙い）が、ページ数を増やしたくないこと・一覧の絞り込みで用途を満たせることから覆した。動線の独立性より既存 UI への統合を優先する。

改訂履歴: 2026-07-08、専用ページ `/bookmarks` 案 → 単語一覧の絞り込みへ変更（03 UI セッションで覆し）。
