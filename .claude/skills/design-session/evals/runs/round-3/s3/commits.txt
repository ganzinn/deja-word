+### 決定 1: ブックマークの付け外しは星アイコンのトグルで行う
+
+単語一覧の各行と単語詳細画面に星アイコンを置き、クリックで付ける/外すを切り替える。アイコンの状態（点灯＝ブックマーク済み / 消灯＝未ブックマーク）で現在の状態を示す。星は、ユーザーが閲覧できる単語であればシステム単語・自作単語（MY）を問わず表示する（ブックマークはユーザーごとの UserWordBookmark で保持するため、単語の所有者を問わない）。
+
+採用理由: 付け外しの起点を、閲覧中のその単語のそばに置くのが最短の操作導線になる。星はブックマーク/お気に入りの慣用表現で意味が伝わりやすい。一覧・詳細の両方に置くことで、どちらの画面からでも同じ操作で完結する。
+
+却下した代替案:
+- 一覧行のみ・詳細のみのどちらか一方に置く。詳細を開かず一覧で素早く付け外ししたい場面と、単語をじっくり見てから付けたい場面の双方があり、片方だけでは動線が途切れるため却下。
+- 行のケバブメニュー（… の中）に「ブックマークする」を入れる。1 タップ増え、状態の可視性も落ちるため却下。
+
+補足（04 への申し送り）: 各行・詳細が現在のブックマーク状態（真偽値）を知る必要がある。状態の取得経路と、クリック時の永続化（Server Action か等）・楽観的更新の可否は 04 で決める。
+
+### 決定 2: 見返す絞り込みは既存の単語一覧ツールバーに追加する
+
+単語一覧ページ `/words` の「単語ビュー」の絞り込みツールバー（`word-list-toolbar.tsx`）に「ブックマーク済みのみ表示」の絞り込みを追加する。既存の絞り込み（フリーワード検索・一致方法・並び順）と同じく URL クエリ駆動とし、既存の方式（`buildWordsHref` / `router.replace` による URL 同期）に合わせる。
+
+採用理由: 専用ページを設けない（01 決定 2）方針のもとで、見返す動線を既存の絞り込み機構に一本化するため。URL クエリ駆動に揃えることで、絞り込み状態の共有・ブックマーク可能なリンク・戻る動線が既存挙動と一貫する。
+
+却下した代替案: 掲載箇所ビュー側にも同じ絞り込みを設ける。ブックマークは単語単位（01 決定 1）で「見返す」対象も単語なので、単語ビューに置けば用途を満たす。掲載箇所ビューへの展開は必要性が確認できず、スコープを絞るため今回は入れない。
+
+補足（04 への申し送り）: 絞り込みを表す URL クエリのキー名・デフォルト値の扱い（既存同様デフォルトは URL に載せない）と、サーバー側の絞り込みクエリ（ブックマーク済みだけを返す取得）は 04 で決める。
+
+### 決定 3: 絞り込み適用時も通常の単語一覧と同じ表示項目とする
+
+ブックマーク済みのみを絞り込んで表示している状態でも、行の表示項目は通常の単語一覧（単語ビュー）と同一とする。ブックマーク一覧専用の表示（専用の列・レイアウト）は作らない。
+
+採用理由: 同じ一覧に絞り込みをかけているだけなので、表示が切り替わらない方が理解しやすい。専用表示を持たないぶん実装・保守も単純になる。現行の表示項目（見出し語・MY バッジ・発音ボタン・品詞・意味）で見返す用途は満たせる。
+
+却下した代替案: ブックマーク時の追加情報（付けた日時など）を専用列で見せる。現状その需要は確認できておらず、必要になれば別途足せるため今回は作らない。
