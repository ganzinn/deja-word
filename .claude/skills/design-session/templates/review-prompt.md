チェック観点（各指摘に重要度 高/中/低 を付けること）:

1. 成立しない記述: 情報の出どころが説明できない値・処理（実コードと突き合わせる）
2. 二重定義・冗長な入力（トピック間で互いに相手の決定として参照し合う循環参照を含む）
3. 決定間の矛盾（同一ファイル内・他トピックの「前提」再掲・ハブのサマリとの間）
4. 不正確な説明: 例示・括弧書き・分岐条件が実際の挙動・引用元の ADR と一致するか
5. 曖昧なシグネチャ・未定義の用語・正常系のみの記述
6. 昇格漏れ・反映漏れ: ハブのサマリ・状態表・他ファイルの「前提」が決定と一致するか。「前提」が決定元トピックの決定範囲を超えていないか

指摘対象外: 委譲先トピックの検討事項リストに明示済みの未決事項、文体の好み、採用理由の肉付け要求。
