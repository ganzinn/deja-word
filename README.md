# DejaWord

登録した英単語をいろいろな形で問い直し、忘れかけた単語を**定着するまで覚え直す**英単語学習 Web アプリです。10 種類の出題形式でテストし、間違えた単語は定着モードで繰り返し出題します。

リポジトリ名は _déjà vu_ + _word_ に由来します。登録・テスト・定着モードで同じ単語に何度も出会い、既視感を重ねて覚えていきます。

## 特徴

### いろいろな形でテストする

- **10 種類の出題形式** — 四択・自己判定・多義語選択・スペル確認・TG 例文（例文から意味や英文を答える形式）の 5 系統を、英語→日本語／日本語→英語の 2 方向で出題します。同じ単語でも、選ぶ・思い出す・書くで問われ方が変わります。
- **範囲と量を決めて出題** — 掲載箇所（単語帳や教材）と掲載番号で出題範囲を、出題数と 1 問ごとの制限時間で分量を決められます。広い範囲から数問だけ抜き打ちで確かめることもできます。
- **苦手だけを出題** — ブックマークした単語に絞ってテストできます。

### 定着するまで繰り返す

- **定着モード** — テストで間違えた単語・うろ覚えの単語を、決めた回数だけ連続で正解するまでラウンド形式で出題します。残り回数が 0 になった単語が「定着」となり、出題から外れます。
- **中断と再開** — 進行中の定着モードは途中でやめても、あとから続きを再開できます。

### 出会った単語を記録する

- **その場で記録** — 必須は単語（見出し語）だけ。意味・訳語・例文・関連語・メモ・掲載箇所は必要な分だけ足せます。AI Gateway が利用できる環境では、意味・発音記号・熟語・例文の下書きを AI が生成します。
- **重複登録の警告** — すでに登録済みの単語を入力すると、警告と既存の単語への「詳細」リンクが出ます。「以前も登録していた＝忘れていた」に気づくための、アプリ名の由来にもなっている入口です。
- **発音を聞ける** — 意味・関連語・例文に発音音源（mp3）を登録して再生できます。未登録の単語も、設定で端末内蔵の自動音声（TTS）による代替再生を有効にできます。

## 技術スタック

- フロント / バックエンド: Next.js 16（App Router）+ TypeScript
- UI: Tailwind CSS v4（CSS ベース設定）+ shadcn/ui（Base UI）
- DB: PostgreSQL（ローカルは Docker Compose）
- ORM: Prisma 7（driver adapter 方式、`@prisma/adapter-pg`）
- 認証: Better Auth（メール + パスワード）
- 発音音源の保管: Vercel Blob（ローカルはディスク driver）
- AI: AI SDK + Vercel AI Gateway（単語の下書き生成。未設定なら機能ごと非表示）
- パッケージマネージャー: pnpm
- ランタイム管理: mise（Node / pnpm を exact pin）
- デプロイ先: Vercel（production は「Create Release」ワークフローの実行で自動デプロイ。詳細は [`docs/ops/release-deploy.md`](./docs/ops/release-deploy.md)）

## セットアップ

前提として、[mise](https://mise.jdx.dev/)・Docker・pnpm が利用できる環境を想定しています。

1. `.env` を作成し、`BETTER_AUTH_SECRET` に `openssl rand -base64 32` の出力値を設定します。

   ```bash
   cp .env.example .env
   ```

2. PostgreSQL を起動します。

   ```bash
   docker compose up -d
   ```

3. Node / pnpm のバージョンを固定します（初回のみ）。

   ```bash
   mise install
   ```

4. 依存関係をインストールし、初回マイグレーションを適用します。

   ```bash
   pnpm install
   pnpm db:migrate
   ```

5. 開発サーバーを起動します。

   ```bash
   pnpm dev
   ```

   <http://localhost:3000> にアクセスして動作を確認してください。
