# ADR-0002: mise + engines + packageManager の3点同期による exact pin

- ステータス: 提案
- 確信度: 中
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

Node.js / pnpm のバージョン差異による挙動差・ロックファイル差分を避けるため、言語ランタイムとパッケージマネージャのバージョン管理方法を決める必要があった。

## 決定内容

Node.js（24.15.0）と pnpm（10.33.0）を範囲指定ではなく **exact バージョンで pin** し、以下の 3 箇所を常に同期させる:

1. mise 設定（開発環境のランタイム切替）
2. `package.json` の `engines`
3. `package.json` の `packageManager`（corepack）

バージョン更新時は 3 箇所を同時に更新する。

## 採らなかった代替案

- メジャーバージョンのみの範囲指定（`^24` 等）—（推定）環境間の再現性が exact pin より劣るため採らなかったと考えられるが、理由の記録はリポジトリ内に無い

## 影響

- 開発者間・CI・Vercel ビルドでランタイムバージョンが一致し、環境起因の差異が排除される
- バージョンアップは 3 箇所同時変更の手間を伴う（片方だけ更新すると不整合エラーになる）

## 根拠（コード・コミット・文書参照）

- `package.json` — `engines.node` / `packageManager` の exact 指定
- mise 設定ファイル（リポジトリルート）
- commit `15bad7b` "M1: プロジェクト土台を実装"（導入時点。理由の記載なし）
