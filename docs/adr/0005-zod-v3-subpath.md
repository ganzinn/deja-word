# ADR-0005: zod v4 パッケージを zod/v3 サブパス API で統一使用

- ステータス: 提案
- 確信度: 中
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

パッケージとしては zod v4 系（`zod ^4.x`）を導入しているが、スキーマ定義は `.cuid()` など v3 互換 API で書かれている。zod v4 は `zod/v3` サブパスで v3 互換 API を提供している。

## 決定内容

すべてのスキーマ定義で **`zod/v3` サブパスから import** する。`"zod"`（v4 API）からの import を混在させない。

## 採らなかった代替案

- v4 API への全面移行 — 現状採られていない。（推定）既存スキーマが v3 API で書かれており、混在すると型が壊れるため現状維持としていると考えられるが、v3 に留まり続ける判断か暫定かは記録が無い

## 影響

- `"zod"` から import すると型が合わず壊れるため、新規スキーマも `zod/v3` に揃える必要がある（`src/CLAUDE.md` に規約として明記）
- スキーマは `src/lib/schema/` に集約され、client / server で共有される（[ADR-0016](0016-server-action-result-type.md) のフォーム連携と一体）

## 根拠（コード・コミット・文書参照）

- `src/CLAUDE.md` — 「zod は `zod/v3` サブパスから import」規約
- `package.json` — `zod ^4.x`
- `src/lib/schema/*.ts` — 実際の import 実態
