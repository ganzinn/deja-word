# ADR-0020: 機能名は quiz（「テスト」を code 上の命名に使わない）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

単語テスト機能の設計開始時、ディレクトリ名・コード上の命名を「test」にするとソフトウェアテスト（`*.test.ts`）と紛らわしいという問題があった。

## 決定内容

**機能名は quiz** とし、ディレクトリ名・コード上の命名は quiz を基準にする。`*.test.ts` はソフトウェアテスト専用に予約する。UI 上の日本語表記は「テスト」のままでよい。

## 採らなかった代替案

- `test` を機能名に使う — ソフトウェアテストとの衝突を理由に却下（`docs/design/word-quiz/README.md:17` に明記）

## 影響

- `src/lib/quiz/`、`src/app/quiz/`、`QuizFormat` / `QuizAnswer` / `QuizMode` 等、コード命名は quiz 系で一貫している
- naming-book に確定用語として収録され、コードと UI ラベル（「テスト」）の対応が管理されている
