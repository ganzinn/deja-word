# ADR-0021: 任意起動の腕試しモデル（SRS はスコープ外）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

quiz 機能の核となる体験として、SRS（間隔反復。アプリが復習スケジュールを管理し「今日再会すべき単語」を提示する方式）と、ユーザーが任意のタイミングで起動する腕試し方式のどちらを採るかが検討された。

## 決定内容

**任意起動の腕試し**を核とする。SRS は将来拡張とし、MVP では持たない。

## 採らなかった代替案

- **復習期限ベース（SRS）** — 設計時に提案されたが、ユーザーの意図が任意起動の腕試しであったため見送り。これにより MVP では復習スケジュールの永続化が不要になった

## 影響

- 復習スケジュール系のテーブルが存在せず、履歴は QuizAnswer の append-only のみ（[ADR-0024](0024-no-quiz-session-table.md)）
- 「中断 = 破棄」（[ADR-0023](0023-batch-submit-discard-on-abort.md)）や「カンニング許容」（[ADR-0025](0025-server-side-generation-cheating-accepted.md)）など、後続判断の多くが「気軽な腕試し」という位置づけを前提にしている
- 将来 SRS を足す場合も、出題対象の選定側だけが変わり生成側は無変更で済む見込みが設計に記録されている
