# ADR-0023: 履歴は終了時一括送信、中断 = 破棄（再開なし）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

テスト進行中の解答をいつサーバへ送るか（逐次 / 一括）、および途中離脱時の扱い（再開 / 破棄）を決める必要があった。テスト進行はクライアント完結が要求されていた。

## 決定内容

- 解答履歴は**テスト終了時に一括送信**する
- **中断 = 破棄**。途中再開機能は持たない。離脱時は確認ダイアログで意思確認する

## 採らなかった代替案

- **解答のたびの逐次送信** — クライアント完結の要求および「中断 = 破棄」と矛盾するため却下
- **確認なしで即破棄** — 誤操作で結果が消えるため却下

## 影響

- 進行状態の永続化が不要になり、サーバ側は生成と一括受領の 2 点だけになった
- 一括送信の整合性（二重送信・単語削除との競合）は single-flight + 存在フィルタで担保する（[ADR-0032](0032-history-submit-single-flight.md)）
- 中断 = 破棄のため、生成に使った乱数シードも永続化しない（[ADR-0028](0028-rng-injected-pure-generation.md)）
