# ADR-0025: サーバ側で問題を全生成し正答をペイロード同梱（カンニングは明示的に許容）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

問題（設問・選択肢・正答）をどこで生成するか。テスト進行はクライアント完結（[ADR-0023](0023-batch-submit-discard-on-abort.md)）のため、進行中にサーバへ正誤判定を問い合わせない前提だった。

## 決定内容

- **サーバ側でテスト全体を一括生成**し、正答を含むペイロードをクライアントへ渡す。進行・判定はクライアント完結
- DevTools でペイロードを覗けばカンニングできるが、**任意起動の腕試しアプリであり不正対策は不要と明示的に許容**する（設計に明記）

## 採らなかった代替案

- **クライアント側生成** — ペイロード肥大とロジックのクライアント配置を理由に却下
- 設問ごとのサーバ判定 —（推定）クライアント完結の要求と矛盾するため俎上に載らなかった

## 影響

- ペイロードは discriminated union（`src/lib/quiz/payload.ts`）で形式ごとに型付けされ、生成純関数群（[ADR-0028](0028-rng-injected-pure-generation.md)）の出力になる
- スコア・正誤の自己申告改竄も同じ理由で許容される（履歴はユーザー自身の学習記録でしかない）
