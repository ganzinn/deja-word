# ADR-0027: 意味未登録語は出題対象外（TG 形式のみ例外）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

意味（MeaningText）が未登録の単語は、意味を問う形式の問題を作れない。範囲内にそういう単語が混ざっているときの扱いを決める必要があった。後に TG 例文形式（formats 7–10）が追加され、前提が一部変わった。

## 決定内容

- **意味未登録語は出題対象から除外**する（エラーにせず静かにスキップ）
- **例外: TG 系形式（TG四択 / TG自己判定）は単語自身の意味に依存しない**。TG 例文（`Example.kind = TARGET`）の英文・訳だけで自立して出題できるため、意味未登録でも TG 例文があれば出題対象になる（2026-07-03 の修正で「意味未登録は全形式共通で除外」から TG 例外へ改訂）

## 採らなかった代替案

- **意味なし単語があれば生成エラーにする** — 1 語あるだけでその範囲のテストが開始できなくなり、腕試しの手軽さを損なうため却下
- **登録側で意味を必須にする** — 「とりあえず単語だけメモして後で意味を足す」運用を塞ぐため却下
（いずれも `docs/design/word-quiz/03-algorithm.md` の却下案）

## 影響

- 対象件数のプレビューは「意味未登録で除外された数」を形式によって変えて数える必要があり、TG 例外の導入時に集計バグ（TG 例文あり・意味未登録の単語を誤って除外・誤カウント）が修正された（commit `dada383`）
- 新形式追加時は「その形式の出題可否条件」を対象抽出クエリに反映する必要がある
