# ADR-0034: 制限時間は形式別のオプション設定（QuizDefaultTimeout 子テーブル）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

制限時間は当初の要求には無く、2026-06-13 に追加された。形式によって必要な回答時間が異なる（四択とスペル入力では大きく違う）ため、単一のデフォルト値では成立しない。

## 決定内容

- 制限時間は**オプション設定**（無制限も可）とし、**形式ごとに推奨デフォルト**を持つ
- ユーザーのデフォルト制限時間は形式ごとの行を持つ子テーブル **QuizDefaultTimeout** に保存する
- デフォルト設定が未保存のユーザーには「レコード全体が null のときのみ推奨デフォルトを適用」し、フィールド単位のマージはしない（2026-06-22 の改訂）。ユーザー作成時の seed はしない
- カウントダウン表示は既定で非表示

## 採らなかった代替案

- 全形式共通の単一制限時間 — 形式によって必要時間が異なるため不採用（quiz-01 の追加理由に明記）
- フィールドレベルのデフォルトマージ — 不採用（quiz-02 の 2026-06-22 改訂で「全体 null のときのみ」と明記）

## 影響

- 形式追加時に `timeoutByFormat`（コンパイラ強制）と backfill migration（[ADR-0013](0013-enum-addition-backfill-migration.md)）の両方が必要になる
- タイムアウトは QuizResult の TIMEOUT として履歴に区別記録される
