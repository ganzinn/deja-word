# ADR-0038: drill の形式・制限時間は元テストから継承

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

drill の各ラウンドで出題形式・制限時間を選ばせるか、元テストの条件を引き継ぐかの選択があった。

## 決定内容

**元テストの形式・制限時間を `Drill.format` / `Drill.timeoutSeconds` に保存し、全ラウンドで継承**する。ラウンドごとの選択 UI は置かない。

## 採らなかった代替案

`docs/design/word-quiz/06-drill-mode.md` 決定 4 の却下案:

- **ラウンドごとに形式を選択可能にする** — 却下
- **デフォルト継承 + 変更可能** — 却下

## 影響

- ラウンド開始が 1 タップで済み、定着の反復コストが低い
- 「誤答した形式と同じ形式で定着させる」という一貫性が保たれる
- 形式を変えて復習したい場合は「同じ範囲でもう一度テストする」（[ADR-0042](0042-retest-same-range.md)）→ 新 drill という経路になる
