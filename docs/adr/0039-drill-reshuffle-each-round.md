# ADR-0039: drill は毎ラウンド再シャッフル（位置記憶の防止）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

drill は同じ単語群を複数ラウンド反復する。出題順が固定だと「順番・位置で答えを覚える」ことができてしまい、単語の定着にならない。

## 決定内容

**ラウンドごとに出題順を再シャッフル**する（Fisher–Yates、[ADR-0028](0028-rng-injected-pure-generation.md) の生成基盤を利用）。

**例外: 掲載番号順出題（[ADR-0072](0072-quiz-order-by-occurrence-number.md)）** — 元テストで「掲載番号順に出題する」を選んだ drill（`Drill.orderByOccurrenceNumber`）は再シャッフルせず、毎回同じ掲載番号の昇順で出題する。位置記憶のリスクはユーザーが明示的に選んだ場合に限り受け入れる。既定（OFF）では本 ADR のとおり毎ラウンド再シャッフルする。

## 採らなかった代替案

- **固定順** — 位置記憶で覚えてしまうため却下

## 影響

- ラウンドの問題データは保存されず、開始のたびにサーバで生成される（[ADR-0037](0037-drill-per-source-test.md) の都度生成と一体）
- 選択肢のダミーもラウンドごとに引き直される
