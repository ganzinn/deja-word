# ADR-0040: drill の既定は誤答のみ、正解も含めるのはオプトイン

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

当初の drill は元テストの全単語（正解含む）を対象にでき、「全問正解でも開始可」だった。実際の利用では、定着させたいのは誤答（+ うろ覚え）であり、正解済み単語まで既定で含めるのは反復コストに見合わなかった（と推定される。改訂の動機自体の記録は「既定 OFF に変更」の事実が中心）。

## 決定内容

- **既定は誤答（+ うろ覚え）のみ**を drill 対象とする
- **「正答も出題する」トグル（オプトイン）**を drill 作成時に置く。全問正解かつトグル OFF のときは開始ボタンを無効化する
- 既存設計の「全問正解でも開始可」の記述は「トグル ON のときに限る」と読み替える（quiz-06 決定 9 として改訂記録）

## 採らなかった代替案

- **全単語既定（改訂前の設計）** — 2026-06-24 の決定 9 で上書きされた（設計文書に改訂として記録）

## 影響

- 正解単語の初期残数（`initialCorrectRemaining`）はトグル ON のときだけ意味を持つ
- 設計改訂が「決定 N の追加 + 旧決定の読み替え注記」という形式で行われた先例
