# ADR-0042: 「同じ範囲でもう一度テストする」（sourceRangeFrom/To の保持）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

drill を完了（全単語卒業）した後、学習サイクルとして「元と同じ範囲で新しいテストを受け直す」導線が欲しい。しかし Drill が持つ実効範囲 `rangeFrom/To` は「番号なし単語を含めた実際の出題範囲」であり、ユーザーが指定した元の範囲そのものではない。

## 決定内容

- drill 完了画面に**「同じ範囲でもう一度テストする」導線**を置く
- そのために**ユーザー指定の元範囲を `Drill.sourceRangeFrom/To`（nullable）として実効範囲と別に保持**する

## 採らなかった代替案

`docs/design/word-quiz/06-drill-mode.md` 決定 11 の却下案:

- **実効範囲（rangeFrom/To）の流用** — ユーザーの指定と一致しないため却下
- **クライアント状態のみで受け渡す** — 後日（別セッション）に完了画面から再テストできないため却下

## 影響

- 「実効範囲」と「指定範囲」という 2 種類の範囲が Drill に併存する。用途を混同しないこと（実効範囲は履歴の記録用、指定範囲は再テスト導線用）
- テスト → drill → 再テストの循環が完結し、学習サイクルの UI が閉じた

## 根拠（コード・コミット・文書参照）

- `docs/design/word-quiz/06-drill-mode.md` 決定 11（design/ 削除運用の対象になった場合は本 ADR が引き継ぎ先。PR #88 で実装）
- `prisma/schema.prisma` — Drill.sourceRangeFrom / sourceRangeTo（nullable）
