# ADR-0045: 意味読み上げ音源の廃止（発音音源のみに集約）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

音源機能は当初「発音」と「意味（読み上げ）」の 2 種類を持っていた（PR #8）。しかし「意味（読み上げ）」音源は再生表示に使われておらず、quiz 設計でも「意味音源は quiz では使わない（MVP）」と確認されていた。

## 決定内容

- **「意味読み上げ」音源を廃止**する（2026-06-14、PR #28）。UI・lib・Server Action から撤去し、DB カラム `translation_audio_url` も DROP migration で削除。既存 Blob は一括回収スクリプトで削除
- 音源は**発音（pronunciation）1 種類**に集約する。「translation audio」という概念は以後使わない（naming-book に明記）
- 発音 1 種類になったことで不要になった `AudioSlot` のジェネリック抽象も解消した（過剰抽象の巻き戻し）

## 採らなかった代替案

- カラム・機能を温存して将来の読み上げ機能に備える — 未使用機能の温存より削除が選ばれた（コミットに「再生表示に未使用だったため」と理由明記）。将来必要になれば再設計する

## 影響

- 関連語の発音音源など、後続の音源機能はすべて発音 1 種類を前提に実装されている（`PronunciationAudioManager` は descriptor 方式でエンティティ非依存に一般化、PR #29）
- schema・コードに translation audio の痕跡は無く、復活させる場合は新規設計になる
