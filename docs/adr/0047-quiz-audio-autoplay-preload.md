# ADR-0047: quiz 中の発音は自動再生 + クライアントプリロード、失敗しても進行を止めない

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

quiz の出題時に発音を聞かせたいが、音源の取得待ちで出題が遅れたり、取得失敗でテストが止まったりしてはならない。制限時間（[ADR-0034](0034-per-format-timeout-setting.md)）があるため遅延は公平性にも響く。

## 決定内容

- **出題画面の表示時に発音音源を自動再生**する
- プリロードは「1 問目はカウントダウン中、次問は出題中」に**クライアント側で `new Audio(url)`** により行う。専用 API は追加しない
- **再生・取得の失敗はテスト進行をブロックしない**（無音で進む）

## 採らなかった代替案

- **音声なし** — 却下（quiz-04 の却下案）
- **全問一括プリロード** — 却下（同上）
- **base64 をペイロードに同梱** — 却下（quiz-05 決定 10 の却下案。ペイロード肥大）

## 影響

- 音源 URL はペイロードに含まれるだけで、取得はブラウザの通常の HTTP 経路（dev は `/api/dev-blob/`、本番は Vercel Blob URL）
- TTS フォールバック（[ADR-0046](0046-tts-fallback.md)）とも連動する（quiz 自動再生時の失敗は通知しない）
