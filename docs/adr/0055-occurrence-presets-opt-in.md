# ADR-0055: 共有掲載箇所プリセットは既定 OFF（オプトイン）へ転換

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

system 所有の共有掲載箇所（ターゲット1900 等）は、当初ユーザー作成時に自動でプリセット ON（単語登録フォームのツールバーに常時表示）としてシードされていた。使わない教材のプリセットまで全ユーザーに出る状態だった。

## 決定内容

- **共有掲載箇所のプリセットを既定 OFF（オプトイン）に転換**する（2026-06-25、PR #77）
- ユーザー作成時のプリセット・シードを全経路（サインアップ / 管理者招待 / インポート）で停止し、`seedOccurrencePresetSettingsForUser` を削除
- 既存ユーザーも data migration（`clear_system_occurrence_presets`）で OFF にリセット
- **例外の明示**: ユーザー自身が作る掲載箇所のフォームは `isPreset=true` 既定のまま（自分で作った掲載箇所はすぐ使う意図が明確なため、と推定される carve-out。例外自体はコミットに明記）

## 採らなかった代替案

- **ユーザー作成時に自動 ON（旧仕様）** — 転換により廃止（挙動転換 + データ移行を伴う決定として記録が残る）

## 影響

- プリセットの表示状態は完全にユーザーの設定（`OccurrencePresetSetting`）に委ねられ、シードに依存しない
- 掲載番号の自動採番は自分の掲載箇所のみ・プリセットの従属設定（`autoNumbering ⟹ isPreset`）という関連規約がある（commit `6601aaa`）
