# ADR-0058: 規約はネストした CLAUDE.md に配置し、AGENTS.md はグローバル項目に絞る

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

AI エージェント向けの実装規約が AGENTS.md 1 枚に集積し、どのコードを触るときにどの規約が効くのかが読み取りにくくなっていた。

## 決定内容

- 規約は**「そのコードを触るとき必ず読まれる最も深い層」の CLAUDE.md に配置**する（配置基準がコミットに明記）。現在 8 枚: ルート（`@AGENTS.md` への委譲）、`prisma/`、`scripts/`、`src/`、`src/app/`、`src/lib/`、`src/lib/words/`、`src/lib/quiz/`
- **AGENTS.md はグローバル項目**（テスト、worktree、ops、バックログ運用）に絞ってスリム化する
- 記述スタイルは「肯定形主体 + 理由 + 参照先」（プロンプトガイドのスタイルに準拠、とコミットに記載）

## 採らなかった代替案

- AGENTS.md への一極集中（旧状態） — 触るコードと規約の距離が遠く、読み込み量も嵩むため分割された

## 影響

- 規約の追記先は「どの層のコードの話か」で機械的に決まる
- ドメイン用語は naming-book（[ADR-0059](0059-naming-book-and-issue-backlog.md)]）、設計判断は本 ADR 群、実装規約は CLAUDE.md 群、という文書の役割分担が成立している
