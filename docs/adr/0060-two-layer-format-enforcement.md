# ADR-0060: コード整形は Stop hook + CI format:check の二層で強制

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-07-04

> **注意**: 本 ADR はコード・コミット履歴からの事後的な推定であり、当時の意思決定の記録ではない。
> 当時を知るメンバーのレビューを経てステータスを更新すること。

## 背景

AI エージェントによる編集で整形忘れが混入し、後続の diff を汚すことがあった。

## 決定内容

整形の強制を**二層**にする:

1. **Claude Code の Stop hook** でセッション終了時に自動整形（ローカルで即時に直す層）
2. **CI の `format:check`** で未整形コードのマージを止める（すり抜けを止める層）

## 採らなかった代替案

- どちらか一層のみ — 「二層で防ぐ」ことが導入コミットに明記されている（hook はローカル環境依存ですり抜けがあり得るため、CI が最終防衛線）

## 影響

- 生成・編集されたファイルは最終的に必ず prettier 整形済みになる前提が成立し、整形差分のレビューコストが消える
- ドキュメント追加（本 ADR 群を含む）も `pnpm format` / `format:check` の対象になる
