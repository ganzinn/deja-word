# ADR-0082: 2 個目以降の意味の発音は登録済み音源のみ（自動音声フォールバックを与えない）

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-08-04

## 背景

単語詳細の意味カードは、意味ごとに「発音」ボタンを 1 つ持つ。音源（`Meaning.pronunciationAudioUrl`）が未登録なら見出し語を自動音声で読み上げる（[ADR-0046](0046-tts-fallback.md)）。

このフォールバックは全意味に一律で効くため、**2 個目以降の意味カードにも「見出し語を読むだけ」の自動音声ボタンが並ぶ**。しかし意味（品詞）が違えばアクセント・発音も異なりうる（`record` 名詞 `ˈrekərd` / 動詞 `rɪˈkɔːrd` など）。自動音声は見出し語の文字列を一律に読むだけで、その意味に対応した発音になる保証がない。**その意味の発音として提示されているのに、実際には違う発音を聞かせうる**——学習用途では誤った発音を覚えさせる害がある。

音源は運用上ほぼ先頭 Meaning にしか登録されない（`db:import-audio` も先頭 Meaning 固定）ため、現状 2 個目以降のボタンは事実上すべて自動音声だった。

## 決定内容

**2 個目以降の意味の発音ボタンは、その意味に音源が登録されているときだけ表示する。音源が無ければ自動音声も提供せず、ボタンごと出さない。**

- 実装は `MeaningCard`（`src/components/word-detail-view.tsx`）で `ttsText` を先頭の意味にだけ渡す（`ttsText={isFirst ? headword : null}`）。`AudioPlayButton` は「音源なし・読み上げ語なし」で `null` を返すため、ボタンは描画されない。**`AudioPlayButton` 側は変更しない**（フォールバックを出すかどうかは呼び出し側が決める、という既存の責務分担を維持する）。
- 先頭の意味は従来どおり。単語自体の代表発音として扱い、音源が無ければ自動音声で読み上げる。
- **意味固有の発音は登録済み音源でしか表せない**、という位置づけを取る。音源が無い＝その意味に固有の発音情報が無い、なので何も出さない。
- 対象は単語詳細（意味セクション）のみ。単語一覧・単語テストが扱う意味は先頭 Meaning だけなので影響を受けない（`words-list.ts` / `quiz/generation/material.ts`）。関連語・例文の発音も変更しない。

## 採らなかった代替案

- **現状維持（全意味で自動音声フォールバック）** — 上記のとおり、意味ごとに違う発音を同じ音で提示しうる。学習用途では誤学習の害が「音が出ないより良い」を上回る。
- **2 個目以降も自動音声を出すが、見た目でさらに弱める（別アイコン等）** — [ADR-0076](0076-audio-source-visual-distinction.md) の 2 段階（音源／自動音声）に 3 段階目が増え、区別の学習コストに見合わない。そもそも「その意味の発音ではないかもしれない」は濃淡で伝えきれない。
- **2 個目以降でも先頭の意味の音源へフォールバックする** — 関連語がリンク先単語の音源へ落ちるのは「同じ綴りの語なので発音も同じ」という根拠があるからで、意味違いは逆にその根拠が崩れる場合そのもの。
- **意味ごとに「発音記号があるときだけ自動音声」等の条件を足す** — 発音記号の有無は音源の有無と独立で、条件が増えるだけで「その意味の発音になる保証」は得られない。
- **`AudioPlayButton` に `ttsFallback={false}` のような props を足す** — `ttsText` を渡さないことで同じ結果が得られ、props が増えない。「読み上げ語が無ければ読み上げない」は既存の素直な意味論。
- **設定で切り替えられるようにする** — 「発音が同じとは限らない」は端末やユーザーの好みで変わる事実ではなく、選ばせる筋のものではない。

## 影響

- 単語詳細で、2 個目以降の意味に音源が無ければ発音ボタンが消える。共通単語は先頭 Meaning にしか音源が無いのが通常なので、**複数の意味を持つ単語では 2 個目以降の発音ボタンがほぼ全て消える**のが期待挙動。
- 自動音声フォールバック設定（設定 → 単語全般）は、意味については先頭の意味にだけ効くようになる。関連語・例文への効き方は変わらない。
- 意味カードのメタ行は品詞・発音記号・発音ボタンが全て空になると `empty:hidden` で畳まれる（既存の仕組みをそのまま利用）。
- 2 個目以降の意味に固有の発音を持たせたい場合は、その意味に音源を登録するのが唯一の手段になる（編集画面の音源欄は従来どおり全意味に出る）。
