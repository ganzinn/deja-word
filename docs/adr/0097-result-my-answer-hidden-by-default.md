# ADR-0097: 結果一覧の「自分の回答」は既定で非表示にし、トグルで表示する

- ステータス: 提案
- 確信度: 高
- 起票日: 2026-08-09

## 背景

テスト結果・ラウンド結果の一覧（`ResultList`）は、各行に「正解」と「自分の回答」を常に並べて出していた。「自分の回答」は四択・多義語選択で選んだ内容、うろ覚え・わからなかった・時間切れの固定文言で、正解行の下に 1 行を占める。

結果画面は「正解を確認して覚え直す」ために見る画面で、自分の誤答は毎回必要な情報ではない。常時表示だと 1 行あたりの高さが増えて一覧の一覧性が落ち、正解より先に自分の誤答が目に入る（2026-08-09 ユーザー依頼「非表示に切り替えられるようにしたい／デフォルトでは非表示」）。

## 決定内容

1. **「自分の回答」は既定で非表示**にし、結果一覧上部のチェックボックス「自分の回答を表示」で表示する。既存の「間違えた問題だけ表示」と同じ行に並べる（表示切替の導線を 1 か所にまとめる）。
2. **状態は `ResultList` のローカル state**（`showMyAnswer`）で持ち、永続化しない。結果画面へ入るたびに既定（非表示）へ戻る。「間違えた問題だけ表示」と同じ扱い。
3. **非表示中も定着モードの残数バッジ（あと◯回 / 定着 / 削除済み）は行に残す**。バッジは「自分の回答」行の右端に置いているため、行そのものは残数がある限り描画し、左側の回答テキストだけを落とす。
4. **回答内容を持つ行が 1 つも無い一覧ではトグルを出さない**（自己判定だけで構成され、うろ覚え・わからなかった・時間切れも無い結果）。押しても何も変わらないトグルを置かないため。判定は誤答フィルタと同じく全行ベースで行い、絞り込みでトグルが出入りしないようにする。
5. **正解の表示は変えない**（常時表示）。隠す対象は自分の回答だけ。

## 採らなかった代替案

- **常時表示のまま（従来）** — 依頼の目的（既定で視界から外す）を満たさない。
- **ユーザー設定（`settings/quiz-defaults`）へ永続化する** — 設定項目が増える割に、切替は結果画面 1 枚の一時的な見せ方の問題。同種の「間違えた問題だけ表示」も非永続で、揃えた。
- **行ごとの個別開閉（アコーディオン）** — 一覧を見比べたいときに行数分の操作が必要になる。一括切替のほうが目的（復習中に必要になったらまとめて確認する）に合う。
- **正解も同時に隠して「答え合わせ」形式にする** — 正解の確認が結果画面の主目的なので隠さない。

## 影響

- 定着モードのラウンド結果・再テスト結果（`DRILL` / `DRILL_RETRY`）でも同じ挙動になる（同一コンポーネント）。残数バッジは決定 3 のとおり非表示中も出る。
- 結果一覧の行は既定で 1 行ぶん低くなる。`docs/features/word-quiz.md` / `drill.md` の該当記述と、結果一覧が写るスクリーンショット（`quiz-result.png` / `drill-round-result.png` / `bookmark-quiz-result*.png`）を更新した。
- 「自分の回答」行の描画条件が「回答内容がある」から「（表示 ON かつ回答内容がある）または残数バッジがある」に変わる。回答内容の有無の判定は `hasMyAnswer()` に切り出し、トグルの表示可否と行の描画条件で共有する。
