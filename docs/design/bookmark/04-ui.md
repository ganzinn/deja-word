## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 付け外し導線は 4 箇所: 単語一覧の行・テスト結果一覧の行・単語詳細画面・quiz の単語詳細ダイアログ。トグルボタン自体が ON/OFF 状態を可視化する（01 確定）。
- 単語一覧に「ブックマークのみ」フィルタを追加する。専用一覧画面は作らない（01 確定）。
- quiz 開始フォームに「ブックマークのみ」チェックボックスを追加。既存の掲載箇所 Select＋番号範囲 Input は残し、掲載箇所未選択＋チェック ON を許す（01 確定）。
- 解答直後の正誤表示画面での付け外しはスコープ外（01 確定）。
- ブックマークは side table `Bookmark`（複合 PK userId × wordId、行があれば ON、保持カラムは createdAt のみ）（02 確定）。
- quiz 開始入力に `bookmarkedOnly: boolean`（必須、日本語名「ブックマークのみ」）を追加。掲載箇所未選択を許すのは bookmarkedOnly=true のときのみで、そのとき範囲（rangeFrom/rangeTo）も未指定であることをスキーマで拒否する（03 確定）。
- プレビューの対象件数・除外内訳はブックマーク済み単語にスコープされる。掲載箇所未選択時は noNumber が null になる（03 確定）。
- 対象 0 件（ブックマーク 0 個＋チェック ON 含む）は既存流儀どおりプレビュー 0 件表示・開始不成立。UI 上の案内表示は 04 の裁量（03 確定）。
- Drill は掲載箇所なしに対応する（occurrenceId / rangeFrom / rangeTo が nullable、`sourceBookmarkedOnly` 追加）。結果画面の定着モード導線はブックマーク全件テストでも出す（03 確定）。
- QuizDefaultSetting に `bookmarkedOnly Boolean?` を追加し、開始画面の「デフォルトとして保存」対象に含める（03 確定）。
