# 03. UI・文言とテスト戦略

状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 訳語の表示制御は形式ごとに別設定を持たせず、1 つの共通設定に統合する（ユーザー合意、設計開始時）。
- 共通設定は出題データの生成時に反映し、四択（英→日）の選択肢と日→英 3 形式（四択・自己判定・スペル確認）の問題文にだけ効かせる。結果一覧はその再表示なので該当列（四択（英→日）の正解列と「自分の回答」列、日→英 3 形式の問題文列）にも同じ内容が出る（01 確定）。
- ON は最初の Meaning の先頭 MeaningText 1 つ、OFF は「; 」連結。既定値は未設定＝ON（01 確定）。
- 自己判定（英→日）の解答表示と結果一覧のその正解列で、先頭 Meaning の先頭訳語をアプリが常時（設定非連動で）赤字にする。装飾記法とはベース＋後勝ちで重ねる（01 確定）。
- 自己判定（英→日）の赤字は ADR-0083 の「訳語には色を付けない／訳語が出る全画面で同じ体裁」をその解答側に限って覆す（01 確定）。
- 先頭の訳語だけでは答えが一意に定まらない問題文は許容する（避けたい場合は開始フォームで OFF）（01 確定）。
