状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 発動条件は「有効な検索語（正規化後キーワードが空でない）あり、かつ可視範囲（system＋自分）に検索語と完全一致する headword なし」。表示上の絞り込み（ブックマーク・ページング）には依存しない（01 確定）。
- 完全一致は「正規化後キーワード（ADR-0084）と headword の等値比較・大文字小文字を区別しない」。照合規則は検索と一貫させる（01 確定）。
- 検索仕様そのもの（照合規則・一致方法・並び順・ページング）は変更しない（01 確定）。
- 導線は単語ビューの件数行直下に 1 箇所、発動条件成立時のみ表示。リンク先は登録フォーム（`/words/new`）に検索語と戻り先コンテキストを渡す URL で、パラメータ設計は 03 で決める。件数行（ResultCount）の表示は従来どおり trim 済み入力値のままで変更しない（02 確定）。
- 導線の表示語と登録フォームへのプリフィル値は正規化後キーワードで統一する。大文字小文字は保持（正規化はアクセント記号除去と trim のみ。小文字化しない）（02 確定）。
- この画面表示は ADR-0084「入力のまま見せる」方針の例外のため、実装 PR で ADR-0084 に例外を追記する（変更対象一覧に含める）（02 確定）。
- プリフィル値に対する初期表示時の重複チェックは追加しない（既存の blur 発火のまま）。登録完了後の遷移も既存のまま（02 確定）。
- 導線経由時の「戻る」は元の検索条件（`q` / `sort` / `match` / `bookmarked` / `page`）の一覧へ戻す。受け渡しの具体設計（`returnHref` の create 対応か別方式か・検証）は 03 で決める（02 確定）。
