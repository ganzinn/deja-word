# 03. 出題・選択肢生成アルゴリズム

状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 機能名は quiz。
- 任意起動の腕試し型。出題対象は Occurrence＋掲載番号の範囲指定で決まり、範囲内の単語を全て出題する。アルゴリズムによる取捨選択はしない（01 確定）。
- 復習期限ベース（SRS）・復習間隔の管理は MVP スコープ外（01 確定。将来拡張）。
- 出題順序はランダム（毎回シャッフル）（01 確定）。
- 出題形式は英→日の3形式: 四択＋「わからない」 / 自己判定 / 多義語選択（選択肢数ランダム）。将来形式4・5（日→英）の追加に耐えること（01 確定）。
- 四択の選択肢は、日本語訳に複数の意味がある場合全て表示し、最初に登録した意味を目立たせる（01 確定）。
- テスト内容はカウントダウン画面の間にクライアントへ全ロードし、テスト中はサーバー通信なしで進行する（01 確定）。

## 検討事項リスト

- [ ] 四択のダミー選択肢（誤答3つ）の生成方法（他の登録単語の意味から選ぶか、その出所・選定基準。登録数が少ない場合のフォールバック）
- [ ] 多義語選択形式の選択肢構成（正解＝その単語の全意味＋ダミーの混合方法、選択肢数のランダム範囲、意味が1つしかない単語の扱い）
