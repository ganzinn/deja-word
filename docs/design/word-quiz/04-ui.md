# 04. UI（画面遷移・画面仕様）

状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 機能名は quiz（ルーティング・コンポーネント命名の基準）。
- 既存 UI は shadcn/ui ベース、画面は App Router（`src/app/` 配下）で構成。
- 画面フロー: テスト開始画面 → カウントダウン画面 → 出題画面（×N問） → テスト結果画面（一覧）→（任意で）定着モード drill（01 確定）。
- 開始画面で出題形式と範囲（Occurrence＋掲載番号）を指定する（01 確定）。
- カウントダウン画面は「3・2・1」の演出。その裏でテスト内容をクライアントへ全ロードし、間に合わなければカウント後もローディング表示で待機（01 確定）。
- 出題画面はテスト中サーバー通信なしで進行（01 確定）。
- 出題形式は英→日の3形式: 四択＋「わからない」（複数の意味は全表示、最初の意味を目立たせ他は薄色） / 自己判定（タップで解答表示→自己選択） / 多義語選択（全意味の選択で正解、選択肢数ランダム）（01 確定）。
- 中断（ブラウザバック・リロード・離脱）は破棄。再開機構なし（01 確定）。
