# 04. UI・遷移・アーキテクチャ・テスト戦略

状態: **未着手**

## 前提（確定事項の再掲）

このトピックが依存する決定。覆す場合はハブ（README.md）と決定元の両方を更新すること。

- 対象 3 経路: 単語ビュー由来の詳細ページに前後ナビ新設、掲載箇所コンテキストに bookmarked 追加、テスト結果ダイアログは結果一覧順ナビ（01 確定）。
- スコープ外: 一覧ソート機能の追加・変更、関連語スタック先のナビ非表示の解除（01 確定）。
- 単語ビューコンテキストは `view=word` を判別子に `sort` / `q` / `match` / `bookmarked` を詳細 URL に載せる。`occ` があれば掲載箇所コンテキストが優先、デフォルト値は省略（02 確定）。
- コンテキスト型は kind 付き union `WordDetailNavContext` に一般化し、掲載箇所コンテキストに `bookmarked` を追加する（02 確定）。
- 単語ビュー用隣接クエリ `findAdjacentWordsInWordView` を新設する。戻り値は prev / next の id のみで掲載番号を含めず、単語ビューコンテキストでは詳細画面に掲載番号を表示しない（02 確定）。
- current が絞り込み集合から外れたら前後ナビ非表示（既存踏襲）（02 確定）。
- 戻り・編集リンクはコンテキストから再構築し、`page` は持ち回らない（02 確定）。

- ダイアログの前後ナビ順序は「開いた時点の表示行」のクライアントスナップショット（wordId 配列）。`onOpenDialog` の引数で渡し、quiz-flow が `dialogNavOrder` として保持、スタック深さ 1 のときのみダイアログへ渡す（03 確定）。
- ダイアログのナビ表示条件は `navOrder` 非 null のみで `occurrenceId` に依存しない（全件ブックマークモードでもナビを出す）。隣接が同期的に決まるため、応答待ちのナビ状態（両ボタン disabled・初回はナビ行非描画）は廃止（03 確定）。
- `getAdjacentWordsForDialog` / `findAdjacentWordsByOccurrenceNumber` と隣接応答系 state（`navResponse` / `navCache` / `resolveNavView` / `resolveCurrentNav`）は廃止・置き換え（03 確定）。
- ダイアログの `#N` は詳細応答の掲載箇所一覧から導出する（全件ブックマークモードは `#N` なし・ナビあり）（03 確定）。
- 削除済み単語の行はナビからスキップせず、エラービューでもナビ継続可能（03 確定）。
- ダイアログの先読みは `navOrder` 前後 1 件の詳細のみ（隣接先読みは廃止）。ADR-0086 該当記述の改訂は本トピックのドキュメント更新論点で扱う（03 確定）。
