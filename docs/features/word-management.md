# 単語管理

## 概要

単語管理は、出会った単語を記録し、意味・訳語・例文・関連語・メモ・掲載箇所とともに蓄える中心機能です。
登録した単語は一覧で見返せるほか、単語テストの出題対象になります。同じ単語を登録しようとすると
「以前も登録していた」ことに気づける重複登録の警告が出るのが、DejaWord ならではの体験です。

## 主な画面と操作

### 単語一覧（単語ビュー）

![単語一覧の単語ビュー](./images/words-list-word-view.png)

ログイン後のメニューから単語一覧を開くと、登録済みの単語を一覧できます。単語ビューでは自分の単語
（MY バッジ）と共通の単語がまとめて新着順（または見出し順）に並び、各行に品詞・訳語・発音が表示されます。
上部の検索欄で、英単語を「から始まる／を含む／で終わる」で絞り込めます。各行のブックマークアイコンで
苦手な単語に印を付け、「ブックマークのみ」で絞り込むこともできます（→ [ブックマーク](./bookmark.md)）。

### 掲載箇所ビュー

![単語一覧の掲載箇所ビュー](./images/words-list-occurrence-view.png)

「掲載箇所単位」に切り替えると、単語帳や教材などの掲載箇所を選び、その中を掲載番号順に並べて見られます。
掲載番号の範囲を指定すると、その範囲の単語だけに絞り込めます。掲載番号の付いていない単語は、範囲を
指定したときは除外されます。

### 単語の登録

![単語の登録フォーム](./images/word-new.png)

一覧右上の「＋」から単語を登録します。必須は単語（見出し語）だけで、意味・訳語・例文・関連語・メモ・
掲載箇所は必要な分だけ追加できます。意味には品詞と発音記号を、例文には種別（例文／成句・熟語／TG／MP）を
付けられます。

### 文字の装飾

意味・補足説明・例文とその和訳・関連語の意味・メモ・掲載箇所の詳細では、囲み記号で文字を装飾できます。
フォーム上部の「文字を装飾するには」を開くと、記号と表示結果の対応を確認できます。

| 入力 | 表示 |
| --- | --- |
| `**必ず**` | 太字 |
| `*doing*` | 斜体 |
| `***to do***` | 太字の斜体 |
| `==前置詞 to==` | 赤文字 |
| `__p.42 参照__` | 青の下線（文字色はそのまま） |

`**==赤い太字==**` のように重ねて使えます（`==***赤い太字の斜体***==` のように 3 つ以上も可）。閉じ記号が無いときは装飾されず記号がそのまま表示されるため、
`2 * 3 = 6` のような本文が勝手に装飾されることはありません。

装飾が使えるのは上に挙げた文章系の入力欄だけです。単語（見出し語）・関連語の見出し・発音記号・掲載箇所名で
記号を書くと、そのまま文字として表示されます（これらはスペル確認の正誤判定・単語検索・発音の読み上げに
使われるため、装飾の対象外にしています）。

装飾は単語詳細だけでなく、単語一覧の意味、単語テストの問題文・選択肢・解答・結果一覧にも反映されます。

なお、訳語と TG 例文（英文・和訳）では、語法を表す `do` `doing` が**自動で斜体**になります
（`（to do）` を `（to *do*）` と書く必要はありません）。装飾記法で自分から斜体にした場合と見た目は同じです。

### 重複登録の警告

![重複登録の警告](./images/word-new-duplicate-warning.png)

すでに自分が登録している単語を入力してフォーカスを外すと、「この単語は既に登録されています。」という
警告と、既存の単語への「詳細」リンクが表示されます。これは「一度覚えたはずの単語との再会」に気づくための
DejaWord のコア体験です。警告が出ても登録自体は妨げないので、既存の単語を開いて追記することも、別の掲載
箇所として登録することもできます。

### AI 下書き

![AI 入力ボタン](./images/word-new-ai-button.png)

単語を入力すると「AI入力」ボタンが使え、意味・発音記号・熟語・例文の下書きを AI が生成します。下書きは
フォームの空欄にのみ反映され、手入力した内容は上書きしません。この機能は AI Gateway が利用できる環境でのみ
表示され、未設定のローカル環境などではボタン自体が現れません。

### 単語の詳細

![単語の詳細](./images/word-detail.png)

単語を選ぶと詳細画面が開き、意味（品詞・発音記号・発音音源・訳語）、例文（種別ごと）、関連語（同意語・
反意語・派生語）、メモ、掲載箇所がセクションごとに表示されます。訳語は先頭のものが強調表示され、TG 例文は
プレースホルダ（`〜` など）を色分けして描画します。`do` `doing` は訳語でも TG 例文でも斜体になります
（色分けと `A` `B` の斜体は TG 例文だけです）。関連語に別の単語がリンクされている場合は、そのままその単語へ
移動できます。

例文にも「発音」ボタンが付き、例文の英文（和訳ではありません）を再生できます。発音音源を登録した例文は
その音源を、未登録の例文は端末内蔵の自動音声を鳴らします（→ [設定](./settings.md)）。どちらも使えない
ときはボタン自体が現れません。

### 単語の編集

![単語の編集](./images/word-edit.png)

詳細画面右上の編集アイコンから、登録と同じフォームで内容を編集できます。意味・例文・関連語・メモ・掲載箇所は
それぞれ追加・削除でき、掲載箇所ごとに掲載番号や掲載箇所内での所在などの詳細を残せます。

例文にも「音源」欄があり、意味・関連語と同じように mp3 ファイルを登録・試聴・削除できます。音源の登録は
その場で反映される操作で、画面下の「保存」とは別です。そのため、追加したばかりでまだ保存していない例文には
「音源は保存してから追加できます。」と表示されます（一度保存すれば欄が現れます）。例文の本文や種別を
編集しても、登録済みの音源はそのまま残ります。共通の単語に元から入っている例文には音源欄が出ません
（共通の例文の音源は管理者が用意します）。

## 掲載箇所と掲載番号

「掲載箇所」は、その単語をどこで見た・出会ったかの記録単位で、実際には単語帳や教材の名前
（例: 英単語ターゲット1900）が入ります。「掲載番号」は掲載箇所の中での単語の番号で、掲載箇所ごとに一意です。
1 つの単語を複数の掲載箇所に紐付けることもできます。

掲載箇所と掲載番号は、単語テストの出題範囲を決める単位でもあります。単語テストでは掲載箇所を選び、掲載番号の
範囲を指定して出題します（掲載番号のない単語は、範囲を指定した出題の対象になりません）。詳しくは
[単語テスト](./word-quiz.md)を参照してください。

## 補足

- 意味・関連語・例文には発音音源（mp3）を登録でき、詳細画面や単語テストで再生できます。発音音源が未登録の場合は、
  設定で端末内蔵の自動音声（TTS）による代替再生を有効にできます（→ [設定](./settings.md)）。
- 例文の発音音源は例文ごとに持ちます。単語テストの TG 形式では TG 例文の音源（未登録なら英文の自動音声）が
  鳴り、単語自身の発音音源に切り替わることはありません（→ [単語テスト](./word-quiz.md)）。
- 関連語に発音音源が登録されていなくても、その関連語が別の単語にリンクされていれば、リンク先の単語の
  発音音源を再生します（同じ単語なので発音も同じ）。関連語自身に発音音源を登録した場合はそちらが優先されます。
- 2 個目以降の意味の「発音」ボタンは、その意味に発音音源が登録されているときだけ表示されます（自動音声では
  再生できません）。意味や品詞が変わるとアクセントや発音も変わることがあり、自動音声は見出し語をそのまま
  読み上げるだけでその意味の発音になる保証がないためです。1 個目の意味は単語の代表的な発音として扱い、
  発音音源が未登録なら従来どおり自動音声で読み上げます。
- 再生ボタンは、登録済みの発音音源（＝信頼できる正しい発音）ならマイクのアイコンではっきりした枠線、
  端末内蔵の自動音声なら三角の再生アイコンで薄い表示になり、どちらを聞いているのか一目で分かります。
- 共通の単語（管理者が用意した共有の単語）は、見出し語を変えずに、自分用の意味・例文・関連語・メモを
  追記する形で編集できます。
